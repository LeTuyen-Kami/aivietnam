## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `var(--background)` | Page background and primary surfaces |
| Secondary (30%) | `var(--card)` | Cards, control panels, secondary containers |
| Accent (10%) | `var(--primary)` | Primary CTA and current-live emphasis only |
| Destructive | `var(--destructive)` | End livestream action and destructive confirmations |

Accent reserved for: Start livestream CTA, "Live" status badge, focused primary action states, and recovery CTA in error state.

---

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | `Start livestream` |
| Empty state heading | `Livestream is ready to start` |
| Empty state body | `This session exists in Payload but is not live yet. Start the livestream to begin broadcasting.` |
| Error state | `Unable to start livestream. Check your admin access and stream connection, then try again.` |
| Destructive confirmation | `End livestream`: `Are you sure you want to end this livestream? This marks the session as ended for viewers.` |

Additional guard copy contract:
- Logged-out access to `/broadcaster/[slug]`: redirect to login without rendering broadcaster UI.
- Logged-in non-admin access: show 403 screen with heading `Access denied` and body `Only admins can broadcast livestreams.`
