## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser viewer component -> `/api/stream/token` | Client requests token from privileged server signer route |
| Browser viewer component -> `/api/livestreams/[slug]/status` | Polling path can reveal session data if auth/access not enforced |
| Viewer state transitions -> Stream client lifecycle | Incorrect transitions can leak sessions or create duplicate joins |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-05-04 | S | `src/app/(frontend)/live/[slug]/Viewer.client.tsx` tokenProvider flow | mitigate | Handle token endpoint 401 explicitly with login-required redirect to same viewer route (D-05) and never continue with invalid token. |
| T-05-05 | D | Viewer call lifecycle and polling loop | mitigate | Gate join to live-only status (D-09), use bounded poll interval, and cleanup call/client on all exits (D-11) to avoid resource leaks/rejoin storms. |

</threat_model>
