<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser request -> `/live/[slug]` SSR page | Untrusted callers may attempt to access protected livestream documents |
| Browser request -> `/api/livestreams/[slug]/status` | Polling endpoint can be abused without proper auth/access checks |
| Next.js server -> Payload Local API | Default Local API override can bypass access controls if misconfigured |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | S/E | `src/app/(frontend)/live/[slug]/page.tsx` | mitigate | Enforce server-side auth with Payload and redirect unauthenticated users using D-01 return flow before any protected data render. |
| T-05-02 | E | Local API livestream reads in page and status route | mitigate | Always pass authenticated `user` with `overrideAccess: false` per D-03 and security-critical rule to prevent privilege bypass. |
| T-05-03 | I | Authenticated viewer data caching | mitigate | Force dynamic behavior and avoid shared/public cache responses for viewer route and status endpoint per D-08. |
</threat_model>
